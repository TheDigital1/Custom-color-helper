# Paint Color Tuner (Custom color helper)

A phone-first static web app: pick a named paint color, adjust it with lockable sliders
(LRV, warmth, hue, chroma, lightness, RGB, undertone pulls), compare the original and the
modified color, and find the closest real paints across brands. All color math runs in the
browser; there is no backend.

## Development

```sh
npm install
npm run build:data      # process data/raw/ → public/data (see data/raw/README.md)
npm run dev
npm test                # unit tests (color math, solver, matching, data build)
npm run test:e2e        # Playwright smoke tests at 390×844 and desktop, using fixture data
```

`npm run build:data -- --download` fetches the PaintDB snapshot if it is not in `data/raw/`.

## Deployment

`.github/workflows/ci-deploy.yml` runs type checks, unit tests and the Playwright tests on
every push, and on pushes to `main` builds the data and the site and deploys it to GitHub
Pages. In the repository settings, set **Pages → Build and deployment → Source** to
**GitHub Actions**.
